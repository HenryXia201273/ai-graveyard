## Our Mission

Artificial intelligence evolves rapidly. Many innovative products disappear before their stories are properly documented.

This project preserves:

- Historical software versions
- Original website snapshots
- Product screenshots and demonstrations
- Development and release histories
- Official shutdown announcements
